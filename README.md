# Portable Pantry

Portable Pantry is a web-based recipe recommendation app. Instead of finding a recipe first and then checking whether you have the ingredients, you start with what you already have and get recipes that match. Results can be narrowed by allergies, dietary restrictions, cook time, cook method, meal type, cuisine, calories, spice level, flavor, and difficulty.

This is a class project for IT 326 (Team A) and is not intended for public release.

## Features

**Everyone (no account needed)**
- Enter, edit, and remove ingredients
- Generate and regenerate recipes
- Filter by allergy, dietary restriction, cook time, cook method, meal type, food category, cuisine, flavor, spice level, calories, and difficulty
- Search recipes by name, view recipe details, and adjust portion size

**Registered users (account required)**
- Create an account, log in, log out, change password, manage account
- Save ingredients and favorites to a Pantry
- Save and remove recipes
- Rate recipes (1 to 5 stars), add personal notes, mark recipes as completed
- Adjust profile

## Prerequisites

- [Python](https://www.python.org/downloads/) 3.10 or newer
- [Git](https://git-scm.com/)
- [Ollama](https://ollama.com/download) installed and running
- Access to the team's Supabase project (ask a teammate for the URL and key)

## Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/JaceEng/PortablePantry.git
   cd PortablePantry
   ```

2. **Create a virtual environment and install the backend packages**
   ```bash
   cd backend
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # macOS / Linux:
   source venv/bin/activate

   pip install -r requirements.txt
   ```

3. **Create your `.env` file**

   Copy `.env.example` to `.env` (in the folder `config.py` reads from) and fill in the values:
   ```bash
   cp .env.example .env
   ```
   You need `SUPABASE_URL`, `SUPABASE_KEY`, and `FLASK_SECRET_KEY`. Never commit this file.

4. **Download the Ollama model**
   ```bash
   ollama pull llama3.1
   ```
   Use the same model name you set as `OLLAMA_MODEL` in `.env`. Make sure Ollama is running before you generate recipes.

## Running the App

1. Start Ollama (it usually runs in the background after installing).
2. Start the backend from the `backend` folder:
   ```bash
   python app.py
   ```
   The server runs at `http://localhost:5000` by default.
3. Open the frontend by opening `frontend/index.html` in a browser, or by going to the address Flask serves if the frontend is served by the backend.

## Running Tests

From the `backend` folder with the virtual environment active:
```bash
pytest
```
Tests mock the Ollama client, so no model needs to be running.

- Recipes and calorie values are generated by an AI model and are estimates. Allergen filtering is not a substitute for checking ingredients. Portable Pantry does not provide medical or nutritional advice.
